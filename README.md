# 8343-2

Эксперимент 8343: повтор 8094-3 «Персонализация» для замера возвратности. Вариант 2.

**Аудитория: те, кто баннер 8094 не видел.** Лендинги 8343-1 и 8343-2 идентичны, различает их только номер.

Живой ИИ-чат: модель через ту же Яндекс-функцию, что в 8094; приветствие, чипсы и крючок
«Персонализация» — как в 8094-3.

- События (ГА4 G-VNG605KE2R + Метрика 96171108): `8343_page_view_landing_var2`,
  `first_message`, `continue_chip`, `continue_typed`, `depth3`, `answer_shown`,
  `session_resumed`, `error`, `fallback_proxy` — как в 8094, плюс `8343_returning_8094_var2`.
- Сообщения — в таблицу 8094, вариант `8343-2`.
- Если в браузере остался CID из 8094, он используется и здесь: по CID в таблице видна
  вся история человека. Работает только на домене kirpinev.github.io.
- Автоматические браузеры не пишутся в аналитику и таблицу и не вызывают модель.
